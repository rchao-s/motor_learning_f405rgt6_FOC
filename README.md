stm32F405RGT6+2804电机

2026.8.24

确定 STM32F405 使用 TIM1 中心对齐 Mode 1、PWM Mode 1、高极性输出。
三低侧电阻电流采样使用 ADC 注入组，并与 PWM 同步；

解决 UART DMA 
UART 上电只能打印一次的问题定位为 DMA 发送完成后 tx_busy 没有正确清零，并对 UART DMA 收发代码进行了简化。

完成三相电流采样系数和零点校准
根据驱动板 1mΩ 采样电阻和 INA181A1 20V/V 增益，电流换算系数 CURRENT_GAIN = 50 A/V 。
零电流 ADC 原始值约在 2020~2040，属于正常零点偏置；同时将上电 offset 校准由 100 点提高到 5000 点，提高零点均值的稳定性。

排查并改善零电流采样噪声
最开始母线未通电时三相电流仍有约 ±0.5~0.6A 波动。通过打印 ADC raw、改变 ADC Sampling Time 等方式排查，
确认十几个 ADC count 的瞬时波动会被换算成几百 mA；增大 Sampling Time 后数据稳定性明显改善，说明 ADC 建立时间和多通道切换也是噪声来源之一。

加入三相共模补偿，采样效果明显改善
针对 Ia、Ib、Ic 经常同时向同一方向漂移的问题，利用三相电流理论关系加入 I_common=(Ia+Ib+Ic)/3，
然后三相分别减去公共分量。处理后零电流数据大部分已经控制在约 ±0.1~0.2A，相比最开始明显改善。
