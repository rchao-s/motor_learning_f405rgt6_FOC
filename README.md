排查并改善零电流采样噪声

最开始母线未通电时三相电流仍有约 ±0.5~0.6A 波动。通过打印 ADC raw、改变 ADC Sampling Time 等方式排查，
十几个 ADC count 的瞬时波动会被换算成几百 mA；增大 Sampling Time 后数据稳定性明显改善，说明 ADC 建立时间和多通道切换也是噪声来源之一。


针对 Ia、Ib、Ic 经常同时向同一方向漂移的问题，利用三相电流理论关系加入 I_common=(Ia+Ib+Ic)/3，
然后三相分别减去公共分量。处理后零电流数据大部分已经控制在约 ±0.1~0.2A，加入三相共模补偿，采样效果明显改善。
